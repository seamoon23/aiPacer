# Project Brief

## 이름과 위치

- 프로젝트: AiPacer
- 루트: `C:\codex\app\AiPacer`
- 유틸리티 허브 번호: 01

## 한 줄 목표

주간 남은 AI 용량과 초기화 일정을 입력하면 달콤이가 오늘 가능한 소형, 중형, 대형 작업 횟수를 바로 보여준다.

## 제품 경계

- 정적 웹과 Manifest V3 Chrome 확장 프로그램
- AI 연동, 로그인, 서버, 저장 기능 없음
- Claude 플랜·남은 용량·초기화 일정의 세 입력 묶음과 선택 가능한 사용시간
- 공식 사용량이 아닌 보수적인 추정치
- 캐릭터는 실제 3살 샴고양이 달콤이를 바탕으로 한 굵은 안경의 사감 선생님 코치
- 상태마다 별도 이미지 사용, 화면 문구는 `달콤이 says`로 통일
